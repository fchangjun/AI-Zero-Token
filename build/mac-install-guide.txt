AI Zero Token macOS 安装说明

当前 macOS 安装包尚未接入 Apple Developer ID 签名和公证。通过浏览器下载后，macOS Gatekeeper 可能会拦截 DMG 或 App。

如果打开 DMG 时看到“已损坏，无法打开。你应该将它移到废纸篓”，通常是下载文件带有隔离属性，而不是镜像真的损坏。

临时打开 DMG：

1. 确认 DMG 来自 AI Zero Token 的 GitHub Releases 官方页面。
2. 打开“终端”。
3. 运行下面的命令，文件名按实际下载文件调整：

   xattr -dr com.apple.quarantine "$HOME/Downloads/AI Zero Token-2.0.12-mac-arm64.dmg"

4. 再次双击打开 DMG。

如果打开 App 时看到“Apple 无法验证 AI Zero Token 是否包含可能危害 Mac 安全或泄漏隐私的恶意软件”，可以使用下面的方式打开。

系统设置方式：

1. 将 AI Zero Token 拖入 Applications。
2. 打开“系统设置”。
3. 进入“隐私与安全性”。
4. 在安全提示区域点击“仍要打开”。
5. 再次确认打开 AI Zero Token。

也可以使用 Control 点击：

1. 在 Applications 中找到 AI Zero Token。
2. 按住 Control 并点击 App，选择“打开”。
3. 在确认窗口中再次点击“打开”。

如果 App 仍然无法打开，可以在确认来源可信后运行：

   xattr -dr com.apple.quarantine "/Applications/AI Zero Token.app"

安全说明：

- 这是 macOS Gatekeeper 对未公证应用的标准提示。
- 这不代表当前安装包一定有问题。
- 如果你从 GitHub Releases 官方页面下载，并且版本号与发布说明一致，可以按上面的步骤打开。
- 后续版本接入 Apple Developer ID 签名和公证后，这个提示会消失。
