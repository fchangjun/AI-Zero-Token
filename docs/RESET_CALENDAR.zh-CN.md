# Codex 情报站

在侧栏选择「情报站」，通过「重置动态」「订阅比价」两个标签查看 Codex 重置信号、历史日历和各地区订阅价格。页面沿用 AZT 的界面风格，日期与时间统一使用北京时间（Asia/Shanghai），日历按公告或首次观察日期归档。

## 查看记录

- 有重置预告或有效预测信号时，页面顶部优先展示提示卡片。预告突出重置类型、预计北京时间和待确认状态，中英文来源直接显示；未公布执行时间时明确标注，不推算日期。
- 最近一次公开确认独立保留；没有新预告时，同时明确显示「下一次重置暂无新预告」，方便区分上次完成与下一次动态。
- 点击预告中的「在日历中查看」，会切换到公告所在月份和日期，并恢复「全部」筛选。日历里的预告以橙色和「预告」文字区分，同一天记录较多时优先显示预告。
- 切换月份，或点击「今天」回到当前月份。
- 使用「全部」「普通重置」「储备重置」筛选。
- 点击日期，在同一卡片内阅读当天记录的中文参考译文与英文原文；发布者、平台和公告时间显示为一行，可复制来源链接。
- 两类重置的说明默认收成一行，点击可展开详细解释。
- 「公开确认」来自数据源当前的已执行状态；历史公告本身不等于准确执行时间。
- 「储备重置」表示储备重置发放相关公告，不代表账号额度已经恢复。

公开信号含预测成分。待执行公告的预计时间过去后，仍保持待确认，不会仅凭倒计时判断完成。公开公告也不代表每个已绑定账号已到账，请以账号实际额度为准。

### 普通重置与储备重置

- **普通重置（Regular / automatic reset）**：按公告范围直接刷新符合条件账号的额度，不能保存到以后使用。这里指公开公告中的重置，不是每个账号自己的自然周期重置。
- **储备重置（Banked reset）**：发放一次可保存的重置机会。在 Codex「设置 → 用量」中查看可用次数、作用范围和到期时间，确认后使用。发放本身不表示当前额度已刷新；它不是现金或 API 余额，也不会永久提高套餐额度。

类型由公开数据源分类，可能存在分类偏差；具体条件以原文和账号实际状态为准。规则参考 [OpenAI：储备重置的使用方式](https://help.openai.com/en/articles/20001498-how-banked-codex-resets-work)。

### 中英文来源与复制链接

英文内容保留公开 API 原文。中文参考译文从 [Codex 情报站公开快照](https://fchangjun.github.io/AI-Zero-Token/snapshot.json)同步，按来源身份和完整英文原文匹配后缓存；机器生成的内容明确标注「自动译文」，仅供参考。旧缓存中的来源站参考译文继续标明原来源；已确认的源站错配可使用按 ID 和原文双重绑定的本地校订译文，单独标注「AI Zero Token 校订」。没有匹配译文时显示暂无译文，不会用通用摘要冒充逐条翻译；原文更新后旧译文不会继续显示。

来源正文直接显示，中文在上、英文在下。卡片底部简短标注译文来源，完整说明可悬停查看。点击「复制来源链接」取得原始地址；平时不再重复展示完整 URL，也不提供浏览器打开按钮。复制失败时显示可选中的地址，方便手动复制。

## 订阅比价与分享

在「订阅比价」查看 Plus / Pro 的美区常规价与已收录地区最低月价，以及各档位低价地区 Top 3。地区明细支持套餐、渠道、地区搜索和价格排序，同时保留当地原价、人民币估算、标准美元价及官方查询地址。价格和汇率显示各自更新时间；网络暂不可用时继续展示已保存数据。最低价仅限已收录地区与渠道，购买资格、税费及最终价格以官方结账页为准。

点击「分享情报」，将当前重置信号、Tibo 中英文消息与 Plus / Pro 低价合成一张图片。分享窗口保留打开时的快照，可保存 PNG、复制带原帖链接的摘要，或使用系统图片分享；系统不支持时保存 PNG。

页面底部的「如需订阅，请联系作者」可打开作者微信二维码，咨询重置提醒订阅方式。本机桌面提醒仍通过「通知设置」控制，并要求 AZT 保持运行。

## 通知设置

打开「通知设置」，分别配置：

- **重置信号提醒**：新的有效公开信号或待执行公告出现时提醒。
- **公开确认提醒**：数据源确认新的重置执行或储备发放时提醒。

点击「保存设置」后在本机持久保存；「取消」不保存修改。提醒使用 AZT 自绘的白色桌面卡片，不再调用系统通知。卡片显示在鼠标所在屏幕的右上角，不抢输入焦点；点击卡片或「查看日历」打开日历，点击 × 关闭。最多保留最近 3 条，空间不足时先收起旧卡片。测试、正式提醒和设置页示例使用同一个卡片模板，测试卡片另有「测试」标记。

预告采用轻松的「补给」文案，但始终区分公开信号、待执行预告和已确认重置。有预计时间时显示北京时间；没有时间时显示「补给在路上，具体几点还得再等等」，预计时间已过也不当作重置完成。确认提醒仍提示以账号实际额度为准；储备重置不代表账号额度已恢复。

卡片不需要系统通知权限，不进入系统通知中心，也不会自动遵循专注模式。共享屏幕时可能被看到；需要安静时请关闭日历里的提醒开关。AZT 必须保持运行，浏览器版没有桌面卡片能力。测试成功表示卡片窗口已显示，不代表用户已经阅读。

首次同步只导入历史，不发送旧记录提醒。同一来源每个阶段显示成功后不再重复提醒；显示失败或退出时未完成发送，会在后续同步中重试仍然有效的当前信号或确认。关闭提醒或环境不支持时仍记录已观察阶段，避免重新开启后补发旧通知。点击卡片可在 macOS 主窗口关闭后重新打开日历；应用已退出时不能接收提醒。

## 同步与缓存

网关监听启动后，后台开始同步，无需保持日历页面打开。默认每 5 分钟检查一次，可点击「立即同步」。页面定时读取本地同步状态，不会调用 Codex 推理或额度刷新接口。

公开接口暂不可用时，可使用情报站中央 JSON 作为备用数据，并明确显示快照时间；较旧快照不会覆盖已同步的新状态。中文参考译文随快照补齐，译文更新不会改变重置状态或触发新的重置提醒。接口恢复后继续实时同步，更新速度仍取决于上游收录、快照发布和网络情况。

数据源暂时不可用时保留已缓存记录并显示同步异常；后台根据失败次数延长自动重试间隔。普通失败后等待 10 秒即可点击「立即同步」或「重试」，无需等待自动重试时间；数据源明确要求限流等待时，手动同步仍遵守 `Retry-After`。页面分别显示自动重试时间和手动重试可用时间。升级后保留旧缓存的自动重试计划，但不再将旧版未区分原因的等待期限用于阻止手动刷新；新的请求若返回限流要求，将记录并遵守。

本地历史、设置和提醒去重记录保存在默认 `~/.ai-zero-token/.state/reset-calendar.json`；设置 `AI_ZERO_TOKEN_HOME` 时使用对应目录。公开数据请求不携带账号 token、邮箱或聊天内容。

## 数据来源

使用 [Codex Resets](https://codex-resets.com/) 的免费公开数据接口，并在页面保留来源链接：[API 文档](https://codex-resets.com/api/docs)。公开源的可用性和更新速度会影响同步；本功能不承诺提前预测下一次重置。

本机管理接口：

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/_gateway/admin/reset-calendar` | 读取本地日历与同步状态 |
| POST | `/_gateway/admin/reset-calendar/sync` | 请求同步，合并并发刷新 |
| PUT | `/_gateway/admin/reset-calendar/settings` | 保存 `signalNotifications`、`confirmedNotifications` 布尔开关 |
| POST | `/_gateway/admin/reset-calendar/test-notification` | 测试桌面通知，返回 `{ sent: boolean }` |

这些接口沿用网关管理接口的本机访问限制，不对远程模型 API 客户端开放。
